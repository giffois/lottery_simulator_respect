# 宝くじ時間体験シミュレータ

宝くじの当せん確率を、時間で見るためのシミュレータです。

## 目的

50万分の1と、2000万分の1。

これは、年末ジャンボ宝くじにおける4等100万円と、1等7億円の当せん確率です。
100万円と7億円の違いは、私たちにもはっきり分かります。
しかし、50万分の1と2000万分の1の違いはどうでしょうか。

数字の上では40倍違います。
けれど、私たちの感覚では、どちらも「とても小さいが、ゼロではない確率」に丸められてしまいます。

人間は、極小確率を正確に認知できるようには進化していません。
一方で、私たちは時間の違いには敏感です。
1秒と1分の違い、1分と1時間の違いなら、身体で分かります。

このシミュレータは、極小確率を購入枚数や期待値ではなく、待ち時間として体験できる形に変換します。
かつて公開されていた宝くじシミュレーターの認知設計へのリスペクトとして作成しています。

宝くじは、夢を見せてくれます。
このシミュレーターは、その夢までの距離を、時間で教えてくれます。

## 非目的

このツールは宝くじの購入を推奨・否定するものではありません。
また、当せん番号の予測や攻略を目的とするものでもありません。

## 使い方

1. `index.html` をブラウザで開く
2. 購入速度モードを選ぶ
3. 開始ボタンを押す
4. 数字が増えていく様子を見る
5. 必要に応じて一時停止・リセットする

## 仕様

- 1枚あたりの価格は300円です。
- 賞金テーブルは、第1082回全国自治宝くじ（年末ジャンボ宝くじ）の当せん金・本数を参考にした「年末ジャンボ宝くじ風」です。
- 抽選は、200組 x 100,000番号の2,000万枚からなる単一のくじセットを買う番号付きモードです。
- 同じくじセット内では同じ券を二度購入しません。2,000万枚を買い切ると完売として停止します。
- 画面には、購入中の券の組・番号と、くじセット内で何枚購入したかを表示します。
- 速度モードは、1倍速、10倍速、100倍速、1000倍速、限界までから選べます。
- 現実換算は「毎週10枚買う」前提で表示します。
- 当選履歴には、等級ごとの回数と合計回収額のサマリーを表示します。
- シミュレーションは教育・娯楽目的であり、実際の当せん結果を予測するものではありません。

## 賞金テーブルの出典

賞金テーブルは、以下の年末ジャンボ宝くじの当せん金・本数を参考にしています。

- 対象: 年末ジャンボ宝くじ
- 回号: 第1082回全国自治宝くじ
- 価格: 1枚300円
- 本数: 23ユニット
- 参照日: 2026年6月24日

このアプリでは、23ユニット合計の本数を1くじセットあたりに換算して使用します。
公式情報は発売回によって変わるため、このアプリでは上記回号を参考にした「年末ジャンボ宝くじ風」の近似テーブルとして扱います。
表示される組番・番号はシミュレーション上のものであり、実際の当せん組番・番号とは関係ありません。

## 実行環境

ビルドや外部サーバーは不要です。
最新のChrome、Safari、Firefoxなどのブラウザで `index.html` を開いてください。
